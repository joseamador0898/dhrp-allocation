# Paper Build

NeurIPS 2026 Evaluations & Datasets track submission:
"DHRP: A Differentiable Hierarchical Risk Parity Architecture and Multi-Universe Portfolio Benchmark"

## Setup

1. Download `neurips_2026.sty` and `checklist.tex` from the
   [official Overleaf template](https://www.overleaf.com/latex/templates/formatting-instructions-for-neurips-2026/bjdwqfdkyftc)
   and place both files in this `paper/` directory.

2. Verify the directory structure:
   ```
   paper/
   ├── main.tex                   # Top-level entry; uses \usepackage[eandd]{neurips_2026}
   ├── references.bib             # 30+ verified citations
   ├── checklist.tex              # NeurIPS 2026 mandatory paper checklist (download)
   ├── neurips_2026.sty           # NeurIPS 2026 style file (download)
   ├── sections/
   │   ├── abstract.tex
   │   ├── 01_introduction.tex
   │   ├── 02_related_work.tex
   │   ├── 03_method.tex
   │   ├── 04_benchmark_design.tex
   │   ├── 05_results.tex
   │   ├── 06_llm_negative_ablation.tex
   │   ├── 07_limitations_discussion.tex
   │   ├── 08_conclusion.tex
   │   └── appendix.tex
   ├── figures/                   # 6 figures, 300 DPI vector PDF
   └── tables/                    # booktabs tables generated from results/*.csv
   ```

## Build

```bash
cd paper/
pdflatex main
bibtex main
pdflatex main
pdflatex main
```

Output: `main.pdf` (≤ 9 pages main + unlimited refs + appendix + checklist).

## Track Options

- **Default (this file)**: `\usepackage[eandd]{neurips_2026}` — anonymized E&D submission
- **Camera-ready**: `\usepackage[eandd, final]{neurips_2026}` — shows author block
- **arXiv preprint**: `\usepackage[eandd, preprint]{neurips_2026}` — author block, no NeurIPS footer
- **Single-blind (E&D only)**: `\usepackage[eandd, nonanonymous]{neurips_2026}` — when full anonymization is infeasible (e.g., dataset attribution requires identifying authors)
